# Transport

- REST Bearer; gRPC `x-api-key`.
- Retries: GET/PUT/DELETE retry on `NetworkError` (only when wrapping a Guzzle `TransferException`), `TimeoutError`, 408/429/5xx. POST retries only with `forceRetry`: `jobs->create()` with an `idempotencyKey`, `jobs->complete/fail/heartbeat`, `workers->heartbeat`. A quota 429 (`RateLimitError::isQuotaExceeded()`) is never retried and never counted by the circuit breaker (it would lock acks out when enqueues hit the plan cap). Request bodies are JSON-encoded once before the retry loop; an unencodable body throws `InvalidArgumentException` instead of looking like a network failure.
- Realtime owns its credentials. `SpooledClient::realtime()` makes no request and never calls `setAccessToken()` on the REST client: SSE uses the API key (or a caller-set JWT) as Bearer; the WebSocket gets a JWT from a provider closure (login cached until `exp - 60 s`, re-checked on every reconnect). Setting the exchanged JWT on `HttpClient` made REST 401 once it expired.
- `SseClient`: read timeout must stay > 0 (0 = busy loop); reconnect attempts are reset only after a connection lived >= 30 s, never on connect (a server that accepts and closes would be retried hot); an idle watchdog reconnects after 60 s of silence.
- Worker (`SpooledWorker`): serial, one job claimed per poll. The forked renewal child (own process group, so group-directed SIGTERM/SIGINT do not kill it mid-drain) renews the running job's lease plus any claimed-but-waiting jobs and sends the worker heartbeat; it exits at `timeout_seconds + 2 s` if the handler is stuck. `stop()` only flips state (it runs inside signal handlers); the job is acked, then deregister is last. Job timeout and `shutdownTimeout` are one SIGALRM raising `JobTimeoutError` / `ShutdownTimeoutError`, which extend `Error` so `catch (\Exception)` in a handler cannot swallow them.
- REST is header-only: the backend 401s credentials passed as `?api_key=`/`?token=`. The sole query-auth routes are `/api/v1/ws` (`WebSocketClient`, JWT only) and the three `/api/v1/events` routes (`SseClient` uses the header anyway). Nothing else may append a credential to a URL — query strings reach proxy/CDN logs, tracing spans, browser history and `Referer` (CWE-598), and API keys do not expire by default.
- gRPC wrapper: unary only (StreamJobs/ProcessJobs in stubs, not exposed).
- `GrpcOptions` default address is `grpc.spooled.cloud:443` unless overridden.
- `GrpcOptions.timeout` is passed to unary generated stub calls as gRPC microsecond timeout.
- Create/enqueue omits unset retry/timeout values so backend queue/server defaults apply; explicit values are still sent.
- gRPC worker registration sends worker type and SDK version; high-level worker registration uses server field names (`queueName`, `hostname`, `maxConcurrency`).
- `WorkerConfig::workerId` (optional, 1-128 chars `[A-Za-z0-9._-]`) is forwarded as `worker_id` and makes REST registration an upsert; omitted means a server-minted UUID per restart, each holding a plan worker-cap slot until the ~2 min stale-worker reaper. Foreign id -> 409.
